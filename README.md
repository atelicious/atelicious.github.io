# Elhy Tablazon - Developer Portfolio

A sleek, responsive, zero-build portfolio website showcasing **Elhy Tablazon**'s 5+ years of software development experience in backend architecture, systems integrations, microservices, and data engineering.

Live URL: **[https://atelicious.github.io/](https://atelicious.github.io/)**

---

## 🚀 Features

- **Resume-Driven**: Highlights real-world impact across 15+ international telecom/aggregator integrations, microservices, and automated data pipelines.
- **Modern Developer UI**: Dark mode by default with instant toggle to light mode, smooth scrollspy navigation, and subtle micro-interactions.
- **Zero Build Dependencies**: Pure HTML5, modern CSS3 (Custom Properties, CSS Grid, Flexbox), and vanilla JavaScript. Deploys natively to GitHub Pages without bundlers or package managers.
- **Interactive Actions**:
  - 1-click **Copy Email** with animated toast feedback.
  - Direct download & view of official Resume PDF (`assets/Elhy_Tablazon_Resume.pdf`).
  - Categorized technical skills matrix (Backend, Languages, Frameworks, Data, DevOps/Tools).
  - Career timeline with detailed responsibilities and technology tags.
- **Mobile First & Accessible**: Responsive across smartphones, tablets, and desktops with keyboard accessibility (`:focus-visible`) and print stylesheet.

## 🛠 Local Preview

To view the website locally, open `index.html` in any modern web browser, or serve it using Python's built-in HTTP server:

```bash
# In the repository root directory:
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.

## 🌐 GitHub Pages Deployment

Since this repository is named `atelicious.github.io`:

1. Any commit pushed to the `main` branch automatically deploys to GitHub Pages at **[https://atelicious.github.io/](https://atelicious.github.io/)**.
2. Verify settings under:
   - **Repository Settings** > **Pages**
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
